The Sidekick Architecture: Layer 3 Worker in an Evaluator Loop

Designed around modern multi-layer agent orchestration, pairing autonomous tool use with structured evaluation and human supervision.

Step 1
User Request + Success Criteria
The user specifies both the intent ("what to do") and the explicit quality bar ("how to judge success").
↓
Step 2
Layer 3 Worker (create_agent)
OpenRouter model equipped with Middleware:
TodoListMiddleware PIIMiddleware ModelCallLimitMiddleware TolerateToolErrors
↓ Tool Calls & Human-in-the-Loop
🌐 Playwright MCP
📁 Sandbox Filesystem
🔎 Google Serper
📚 Wikipedia
👤 Human Help Pause
↓ Draft Solution Produced
Step 3
Evaluator Agent Loop
Inspects the candidate answer strictly against the success criteria.
Criteria Met? → Return Final Answer to User ✅
Needs Clarification? → Pause for Human Input 🙋
Deficient? → Return Constructive Feedback & Retry 🔄 (up to 3 attempts)

🛡️ Guardrails & Resilience

TolerateToolErrors catches browser crashes or HTTP drops and feeds them back as messages so the agent recalibrates instead of crashing. PIIMiddleware scrubs emails and credit cards from prompts and tool outputs.

⚡ State-Preserving MCP

Uses persistent stdio MCP sessions. The browser session stays alive between individual agent turns, preventing loss of logged-in sessions, form states, and navigation history.

🤝 Human-In-The-Loop

When encountering captchas, 2FA, or irreversible actions, the worker invokes request_human_help, pausing execution until the user approves in the UI.

Running the Full Python App Locally

You can clone and run this exact application on your local machine with full Playwright browser interaction:

# 1. Clone this repository
git clone https://huggingface.co/spaces/nakitadev/langchain-sidekick
cd langchain-sidekick

# 2. Configure your .env file
cat < .env
OPENROUTER_API_KEY=your_key_here
SERPER_API_KEY=your_key_here
PUSHOVER_TOKEN=your_token_here
PUSHOVER_USER=your_user_here
EOF

# 3. Run with uv (fast modern Python runtime)
uv run app.py

# Or standard pip:
pip install -r requirements.txt
python app.py
